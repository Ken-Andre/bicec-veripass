# Agent Communication Preferences

These instructions apply to assistant replies in this workspace.

## Style Rules

- Use direct, restrained wording.
- Prefer French wording when the user is working in French.
- Avoid avoidable English terms in French deliverables. Keep only names, acronyms, or terms that are necessary in context.
- Do not use long dash punctuation.
- Do not use theatrical, generic, or model-like phrasing.
- Do not use the banned wording patterns listed below unless the user explicitly asks to discuss or edit the list itself.
