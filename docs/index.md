## Project Overview

**BICEC VeriPass** is a sovereign KYC digital onboarding platform for BICEC bank (Cameroon). It transforms 14 days of manual KYC onboarding into a 15-minute digital journey.

### Project Parts

| Part           | Type    | Technology                                         | Description                                                                        |
| -------------- | ------- | -------------------------------------------------- | ---------------------------------------------------------------------------------- |
| **backoffice** | Web SPA | React 19, TypeScript, Vite, TailwindCSS            | Back-office for Jean (Validator), Thomas (Supervisor), Sylvie (Director), Admin IT |
| **mobile**     | PWA     | React 19, TypeScript, Vite, TailwindCSS            | Mobile onboarding journey for Marie (customer)                                     |
| **backend**    | API     | Python 3.11, FastAPI, PostgreSQL 16, Redis, Celery | KYC API, OCR, biometrics, state machine                                            |

## Quick Start

See [`code/README.md`](../code/README.md) for setup instructions.

### Prerequisites
- Docker Desktop (WSL2 backend)
- RAM ≥ 16 GB
- `.wslconfig` configured (see `docs/setup-wsl2-windows.md`)

### Launch
```bash
cd code
docker compose up --build
docker compose exec fastapi alembic upgrade head
docker compose exec fastapi python scripts/seed_dev.py
```
